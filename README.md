## Reglas y alcance
Se propone desarrollar una versión básica de Pong en lenguaje C, con interfaz 100 % de consola. El jugador controlará una paleta mediante teclado y la computadora controlará automáticamente la paleta opuesta. La pelota se desplazará y rebotará contra los límites y las paletas. Cuando supere una paleta se asignará un punto al contrario. La partida finalizará cuando uno de los jugadores alcance 5 puntos. Se incluirá una opción para abandonar la partida.

La propuesta contempla separar datos/estado, lógica del juego y entrada/presentación.
